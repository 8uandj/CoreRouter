# Current-code load sweep

The retained derived per-seed source is `all_modes_per_seed.csv` (3,360 rows across Vietnam/NSFNET/GEANT2; 20 seeds × 7 intensities × 8 protected/unprotected modes). The original run directory previously cited as `results/rev1/load_sweep/current_code_20261117/` is currently absent, so its raw per-topology files and manifests cannot be revalidated. The retained CSV has matched trace hashes across the eight modes for each topology/intensity/seed; `sources.json` records hashes of the former raw files, not of the retained CSV. All protected admitted hard-violation rates are zero in the retained records.

`all_modes_per_seed.csv` retains every protected and unprotected trial. `all_modes_summary.csv` summarizes safe acceptance, candidate infeasibility, primary rejection categories and admitted hard violations for all 168 topology/intensity/mode groups. `paired_statistics_21.json` is the earlier paired-statistics export. For the mentor-requested consistent zero/tie treatment and complete 21-row table, regenerate `mentor_b2_load_sweep_21.csv`/`.tex` and unprotected load outcomes `mentor_d1_unprotected_load_sweep.csv`/`.tex` from the retained per-seed CSV. The exact procedure, all-zero convention, and missing-original-input limitation are recorded in `mentor_statistics_manifest.json`.

Reproduce retained-data summaries with `venv/bin/python scripts/rev1/summarize_mentor_statistics.py`; this does not run simulations. Recreate the figure with `venv/bin/python scripts/rev1/plot_manuscript_load_sweeps.py` only if the original run-directory CSVs have been restored, because the plot generator currently expects those missing files.

The sweep uses arrival probability min(1, intensity), topology-scaled base TTL 15–60 steps multiplied by scale 1.0/1.4/2.3 with integer rounding, then longer TTL above intensity 1.0. CPU/RAM demand and requested SID depth also scale above intensity 1.0. Different TTLs prevent direct pooling with the long-lived benchmark stress conditions. CI and SD describe evaluation variation at fixed checkpoints; repeated Bursty offered traces do not represent independent traffic realizations.

Upload `figs/load_sweep_three_topologies.pdf` to the manuscript's Overleaf `figs/` directory. Individual `vietnam_load_sweep.pdf`, `nsfnet_load_sweep.pdf`, and `geant2_load_sweep.pdf` are also exported for optional separate presentation. The combined figure is the one referenced by `rev1.tex`.
