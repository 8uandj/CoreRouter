{\Large \bf ABSTRACT}
\vspace{10pt}
\end{center}

Service Function Chaining (SFC) in Software-Defined Networking (SDN) environments enables the dynamic composition of Virtual Network Functions (VNFs) to deliver complex network services. However, practical SFC deployments in geo-distributed data center networks (DCNs) face severe challenges, including latency accumulation, resource fragmentation, and the non-trivial overhead of migrations under dynamic traffic conditions. The adoption of programmable data planes based on Segment Routing over IPv6 (SRv6) and P4 switches introduces fine-grained, source-routed traffic steering but imposes strict hardware limitations—most notably the Maximum Segment Depth (MSD), which defines the strict upper limit of parsing capabilities on an ASIC.

This thesis proposes \textbf{3S-COM} (Smart, Scalable, Secure), a fully closed-loop orchestration architecture that jointly optimizes VNF placement and proactive migration across a geo-distributed backbone network (simulated over 10 primary locations in Vietnam). The core of the system is the novel Joint Optimization of VNF Placement and Proactive Migration (JO-VPPM) framework. 

Moving beyond naive heuristics and basic Deep Reinforcement Learning (DRL), this research architects a robust Deep Graph Reinforcement Learning (DGRL) agent powered by Graph Attention Networks (GAT). A critical innovation lies in modeling the network with a Static Adjacency Matrix alongside an Adaptive Lagrangian Penalty algorithm. This guarantees not only the preservation of the topological spectrum required for mathematical convergence (achieving an Explained Variance of 0.42) but also dynamically self-regulates to aggressively prevent MSD violations. Comprehensive evaluations demonstrate that our JO-VPPM agent achieves an Acceptance Ratio of 63.0\% while fundamentally restricting MSD violations to a mere 12.0\%, profoundly outperforming Decoupled AI baselines which suffer from 30.0\% violation rates.

\chapter{Introduction}
\label{chap:introduction}

\section{Motivation and Background}
The exponential surge in data traffic driven by emerging paradigms such as 5G/6G mobile networks, the Internet of Things (IoT), autonomous vehicles, and high-fidelity video streaming services has placed unprecedented pressure on global telecommunication infrastructures. This digital explosion mandates network architectures that are not only high-bandwidth but also highly agile, scalable, and dynamically programmable. To meet these stringent requirements, the industry has aggressively transitioned from monolithic, proprietary hardware appliances toward Software-Defined Networking (SDN) and Network Function Virtualization (NFV). SDN decouples the control plane from the data plane to provide centralized intelligence and programmability, while NFV abstracts physical network appliances into Virtual Network Functions (VNFs)—such as firewalls, intrusion detection systems (IDS), and deep packet inspectors (DPI)—running on commodity off-the-shelf (COTS) servers. 

The concatenation of these VNFs to deliver complex end-to-end network services is known as Service Function Chaining (SFC). A typical SFC defines the exact sequence of security and processing functions a traffic flow must traverse before reaching its destination. While SFC dramatically enhances service agility, its deployment across geo-distributed data center networks (DCNs), such as long-haul backbone networks spanning an entire nation, introduces severe operational bottlenecks. End-to-end latency accumulates precipitously across vast geographical distances, computational and memory resources become fragmented across distributed edge and core hubs, and the migration of VNFs during unexpected traffic influxes incurs massive state-transfer overheads.

Simultaneously, the evolution of programmable data-planes has revolutionized traffic steering capabilities. Segment Routing over IPv6 (SRv6) has rapidly emerged as the de-facto standard for modern backbone routing. Unlike traditional IP routing which requires maintaining per-flow state across every intermediate switch, SRv6 implements source routing. It encodes the entire routing path and the VNF processing sequence directly into the IPv6 packet header as a stack of Segment Identifiers (SIDs). This allows intermediate P4-programmable switches to forward packets statelessly at line-rate simply by executing the instructions embedded in the packet header.

However, a critical and often overlooked phenomenon threatens the viability of SRv6-enabled SFC: the hardware limitations of modern switching Application-Specific Integrated Circuits (ASICs). The most prominent of these constraints is the Maximum Segment Depth (MSD), which defines the strict physical upper boundary on the number of SIDs an ASIC can parse within a single packet header. When an SFC demands a complex routing path requiring an SID stack that exceeds the MSD of any switch along its route, the hardware simply cannot parse the packet. This results in catastrophic network failures such as packet drops, infinite recirculation loops, and severe latency spikes. 

Despite this imminent threat, existing network orchestration algorithms—ranging from traditional Integer Linear Programming (ILP) and greedy heuristics to modern standard Deep Reinforcement Learning (DRL) agents—habitually abstract the network as an idealized mathematical graph. They either completely ignore the MSD constraint or naively assign it a soft penalty. This fundamental disconnect between high-level orchestration logic and low-level data-plane physics inevitably generates routing solutions that are theoretically optimal in simulation but functionally destructive when deployed to production hardware like the Intel Tofino switches.

\section{Problem Statement}
Given a geo-distributed backbone network, mathematically modeled as a topological graph where nodes represent computational data centers interconnected by high-latency transmission links, the fundamental problem is two-fold: First, how to dynamically place a sequence of VNFs to satisfy incoming SFC requests; and second, how to proactively migrate existing VNFs to mitigate impending traffic congestion. 

The objective is to design an intelligent, closed-loop orchestrator that jointly optimizes VNF placement and proactive migration (JO-VPPM) to strictly minimize end-to-end service latency and operational switching costs. Crucially, this optimization must be strictly constrained by the hardware realities of the data plane. The framework must absolutely guarantee that no computed routing path generates an SRv6 stack that violates the Maximum Segment Depth (MSD) limitation of any traversed programmable switch. 

Solving this requires an orchestration intelligence capable of operating continuously in near real-time, predicting short-term traffic spikes, and fundamentally interpreting the spatial topography of the network to balance resource loads across geographically distant data centers securely.

\section{Highlight of Contributions}
To address the critical divergence between AI-driven orchestration and rigid data-plane physics, this thesis proposes the \textbf{3S-COM} (Smart, Scalable, Secure) architecture. We introduce a novel Deep Graph Reinforcement Learning orchestration framework specifically tailored for geo-distributed backbone environments. The key contributions of this research include:

\begin{itemize}
    \item \textbf{Hardware-Constrained Mathematical Modeling:} A rigorous formulation of the Joint Optimization of VNF Placement and Proactive Migration (JO-VPPM) problem. The model natively embeds SRv6 MSD physical limitations as hard boundaries, directly correlating logical data center processing latency with ASIC degradation vectors.
    \item \textbf{Deep Graph Reinforcement Learning (DGRL):} The development of a topology-aware reinforcement learning agent powered by Graph Attention Networks (GAT). We identify that standard Multi-Layer Perceptrons fail to comprehend geographical routing logic, and demonstrate how utilizing a Static Adjacency Matrix within the GAT preserves the fundamental eigenvalues necessary for the Critic network's convergence.
    \item \textbf{Adaptive Lagrangian Penalty Mechanism:} The design of an adaptive reward structure that dynamically calculates the $\lambda_{msd}$ penalty based on an Exponential Moving Average of historical hardware violations. This mechanism automates the delicate balance between aggressive exploration and zero-tolerance constraint satisfaction, completely eliminating manual reward tuning.
    \item \textbf{Empirical Evaluation on a Geo-Distributed Topology:} The simulation and evaluation of the DGRL agent against complex telecom traffic profiles upon a realistic 10-node Vietnam Backbone topology. The results prove that the DGRL approach achieves an Acceptance Ratio of 63.0\% while aggressively slashing MSD hardware violations to a mere 12.0\%, profoundly outperforming topology-blind decoupled AI architectures.
\end{itemize}

\chapter{Background and Related Work}
\label{chap:background_related}

This chapter establishes the theoretical foundations of the technologies integrated within the 3S-COM framework and provides a critical survey of existing orchestration methodologies. We begin by examining the evolution of Software-Defined Networking (SDN) and Network Function Virtualization (NFV), followed by a deep dive into the physical constraints of Segment Routing over IPv6 (SRv6). Subsequently, we explore the paradigms of Deep Reinforcement Learning (DRL) and Graph Neural Networks (GNN). Finally, we identify the specific research gaps that motivate the development of the JO-VPPM framework.

\section{Technical Background}
\label{sec:background}

\subsection{Network Function Virtualization (NFV) and SFC}
The transition from proprietary, hardware-centric network appliances (Middleboxes) to software-based \textbf{Network Function Virtualization (NFV)} has fundamentally altered service delivery models in telecommunications. NFV enables the instantiation of Virtual Network Functions (VNFs)—such as firewalls, load balancers, and deep packet inspectors—on commodity off-the-shelf (COTS) servers. 

The ETSI NFV Architectural Framework defines three key functional blocks: the \textbf{NFV Infrastructure (NFVI)}, the \textbf{Virtual Network Functions (VNFs)}, and the \textbf{NFV Management and Orchestration (MANO)} stack. The decoupling of functional logic from physical hardware allows for rapid service deployment and elastic scaling, significantly reducing Capital Expenditure (CAPEX) and Operational Expenditure (OPEX).

To provide a comprehensive end-to-end service, these VNFs must be organized into a specific sequence known as a \textbf{Service Function Chain (SFC)} \cite{wang2021drl}. As defined in RFC 7665, an SFC specifies the set of virtual network functions and their strict execution order to be applied to a specific traffic flow. For instance, in a 5G core network, an enterprise traffic flow might traverse a Firewall, followed by an Intrusion Detection System (IDS), and finally a Load Balancer.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{thesis/figs/ETSI-MANO.jpg}
    \vspace{0.5cm}
    \caption{The ETSI NFV Reference Architecture showing the decoupling of hardware/software layers and the MANO orchestrator.}
    \label{fig:etsi_nfv}
\end{figure}

The core challenge in SFC orchestration lies in the \textbf{Joint Optimization of VNF Placement and Routing}. In geo-distributed data center networks (DCNs), this problem is NP-hard. The orchestrator must select optimal data center nodes to host each VNF while ensuring the routing path minimizes propagation latency over a high-latency backbone (e.g., across 10 Vietnamese provinces). Furthermore, it must manage uneven resource distribution and the highly dynamic nature of incoming service requests, particularly in "Elephant" vs "Mouse" traffic scenarios.

\subsection{SRv6 and Network Programming (RFC 8986)}
Segment Routing over IPv6 (SRv6) is a modern source-routing paradigm that leverages the IPv6 data plane. Unlike traditional MPLS-TE, which relies on complex signaling protocols (like RSVP-TE or LDP), SRv6 encodes the network path and service instructions directly into the IPv6 header as a ordered list of \textbf{Segment Identifiers (SIDs)} \cite{filsfils2015segment}. 

The \textbf{Segment Routing Header (SRH)}, as defined in RFC 8754, carries the sequence of SIDs representing the path segments and VNF behaviors. According to the "Network Programming" model (RFC 8986), a SID is not just an IP address but a combination of \textit{Locator:Function:Args}.
\begin{itemize}
    \item \textbf{Locator:} The address of the node that executes the function.
    \item \textbf{Function:} The specific opcode (e.g., End, End.X, End.DX2) to be executed on the packet.
\end{itemize}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{thesis/figs/SRv6.png}
    \vspace{0.5cm}
    \caption{The SRv6 Segment Routing Header (SRH) structure including the Segment List and the Routing Extension Header.}
    \label{fig:srv6_header}
\end{figure}

SRv6 enables a "Stateless Data Plane," where intermediate routers do not need to maintain flow-specific state, greatly enhancing network scalability. However, this efficiency comes at the cost of significantly increased header size, as each SID adds 128-bits (16 bytes) to the packet overhead.

\subsection{Hardware Parsing Constraints: Maximum Segment Depth (MSD)}
While SRv6 is highly flexible in software, its implementation on high-speed programmable hardware faces rigorous physical boundaries. Modern ASICs follow the \textbf{PISA (Protocol-Independent Switch Architecture)} model, which utilizes a pipeline of match-action stages. 

To process an SRv6 packet, the switch's **Parser** must extract and examine the SID stack in the header. The **Maximum Segment Depth (MSD)** represents the maximum number of SIDs that a switch can successfully parse and process from a single IPv6 header in a single clock cycle \cite{qiu2024sfcplanner}. 

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{thesis/figs/The-PISA-architecture.png}
    \vspace{5cm}
    \caption{The PISA Switch Architecture highlighting the Parser stage and the SID parsing bottleneck.}
    \label{fig:pisa_arch}
\end{figure}

If the number of SIDs in an SFC exceeds the hardware MSD, the switch must either drop the packet or perform "Recirculation"—passing the packet through the pipeline multiple times. Recirculation effectively halves the switch's throughput and increases latency, rendering it unusable for carrier-grade URLLC (Ultra-Reliable Low-Latency Communication) 5G services. The JO-VPPM framework identified in this research treats MSD not as a soft penalty, but as a hard physical boundary, ensuring that all computed paths are 100\% feasible on tangible P4 hardware seperti Intel Tofino.

\subsection{Deep Graph Reinforcement Learning (DGRL)}
To address the dynamic and complex nature of geo-distributed orchestration, this research employs \textbf{Deep Reinforcement Learning (DRL)}. The orchestration problem is modeled as a \textbf{Markov Decision Process (MDP)}, defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$, where $\mathcal{S}$ is the state space, $\mathcal{A}$ is the action space, $\mathcal{P}$ is the transition probability, $\mathcal{R}$ is the reward function, and $\gamma$ is the discount factor.

We specifically utilize the \textbf{Proximal Policy Optimization (PPO)} algorithm \cite{schulman2017proximal}, which ensures training stability by clipping the objective function:
\begin{equation}
L^{CLIP}(\theta) = \hat{\mathbb{E}}_t \left[ \min(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t) \right]
\end{equation}

However, standard policy networks based on Multi-Layer Perceptrons (MLP) suffer from "topology blindness," as they treat network state representations as flat feature vectors. To overcome this, we utilize \textbf{Graph Attention Networks (GAT)} \cite{velivckovic2017graph}. GAT allows the agent to explicitly model the substrate network as a graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$, where each vertex represents a data center and edges represent physical links. 

The core of GAT is the attention mechanism, which computes the importance of node $j$'s features to node $i$:
\begin{equation}
e_{ij} = \text{LeakyReLU}\left(\vec{a}^T [\mathbf{W}\vec{h}_i || \mathbf{W}\vec{h}_j]\right)
\end{equation}
By utilizing multi-head self-attention, the agent can weigh the importance of neighboring nodes' resources (e.g., CPU, Memory, available MSD) relative to its current placement decision. This graph-aware perception is essential for understanding the spatial implications of VNF placement on end-to-end latency and hardware feasibility.

\section{Related Work}
\label{sec:related_work}
The problem of SFC orchestration has been extensively studied, evolving from classical optimization to modern machine learning paradigms. We categorize existing literature into three functional domains.

\subsection{Classical Optimization and Heuristics}
Traditional approaches often formulate VNF placement as an \textbf{Integer Linear Programming (ILP)} problem or a variation of the Multi-Dimensional Knapsack Problem. While ILP can find mathematically optimal solutions for small topologies, its computational complexity is NP-hard. 

Heuristic algorithms, such as First-Fit, Best-Fit, or Greedy-based strategies, offer faster execution but frequently fall into local optima. These "Short-sighted" strategies fail to manage long-term resource fragmentation or accommodate proactive migration needs in dynamic 5G environments where traffic flows fluctuate rapidly.

\subsection{DRL-based SFC Orchestration}
Recent work has leveraged DRL to automate SFC placement. Wang et al. \cite{wang2021drl} proposed DRL-SFCP, an adaptive placement strategy using PPO. Similarly, Wu et al. \cite{wu2025drl} demonstrated a fast joint mapping approach using DRL. However, these paradigms typically operate under the assumption of an "ideal" data plane with infinite parsing capacity. They treat hardware constraints as soft penalties in the reward function, which is insufficient for production P4 switches where MSD violations cause binary failure (packet loss).

\subsection{Graph-Aware and Hardware-Aware Approaches}
The integration of Graph Neural Networks with RL is a burgeoning field. Pei et al. \cite{pei2025graph} utilized Graph Pointer Networks (GPN) for network embedding, demonstrating the superiority of topological awareness. In the domain of SRv6, Qiu et al. \cite{qiu2024sfcplanner} introduced SFCPlanner, an online planning approach focusing on SRv6 flow steering. 

Despite these advances, there is a distinct lack of research that jointly optimizes placement and \textbf{proactive migration} while strictly adhering to \textbf{binary hardware limits (MSD)}. Most models either ignore migration costs or fail to perceive the graph spectral stability required for GNN convergence in dynamic environments.

\subsection{Network Model}
We model the substrate network as an undirected graph $\mathcal{G}_s = (\mathcal{N}, \mathcal{E})$. Each node $n \in \mathcal{N}$ represents a Data Center governed by finite resources. Unlike flat DC models, our nodes possess a hardware limit ($MSD_n$) characterizing the parsing depth of the local SRv6-enabled ingress switch.

The objective function of JO-VPPM minimizes the weighted total cost:
\begin{equation}
\min C_{\text{total}} = \sum_{r \in R} \left( \alpha L_{\text{total}} + \beta S_{\text{cost}} + \gamma E_{\text{cost}} \right)
\end{equation}
where $L_{\text{total}}$ is total latency and $S_{\text{cost}}$ is the switching cost of migration.

\textbf{SRv6 Hard Constraint:}
A decision is feasible if and only if:
\begin{equation}
\sum_{k=1}^{\mathcal{J}_r} \text{SID}_k \le MSD_n, \quad \forall n \in \text{path}_r
\end{equation}

\section{Research Gaps}
\label{sec:gaps}
Despite the growing interest in leveraging AI for network orchestration, our analysis of the current literature reveals four critical gaps that remain unaddressed:

\begin{enumerate}[label=RG\arabic*., leftmargin=*, nosep]
    \item \textbf{Hardware - Data Plane Physical Disconnect:} Most existing Deep Reinforcement Learning (DRL) frameworks for SFC orchestration treat hardware processing limits as soft penalties in the reward function. In production-grade programmable switches (e.g., Intel Tofino), the Maximum Segment Depth (MSD) is a non-negotiable physical boundary. Treating it as a "soft penalty" rather than a hard constraint leads to invalid paths that cause immediate packet drops in actual deployments.

    \item \textbf{Reactive vs. Proactive Orchestration in Geo-Distributed Networks:} Current VNF management strategy is predominantly reactive—triggered only after service degradation or resource saturation has already occurred. In geo-distributed networks, the propagation latency of control-plane signaling makes reactive scaling insufficient for high-mobility traffic. There is a lack of integrated pipelines that combine short-term traffic forecasting (e.g., via Bi-GRU) with proactive migration logic.

    \item \textbf{Topology-Blind AI Architectures:} Standard DRL agents utilizing Multi-Layer Perceptrons (MLP) treat network states as unstructured feature vectors. These "topology-blind" agents fail to comprehend the geographical and topological relations of the substrate network, leading to inefficient routing and sub-optimal load balancing between distant core hubs.

    \item \textbf{Training Instability in Graph-Based RL:} When applying Graph Neural Networks (GNNs) to reinforcement learning, the dynamic nature of adjacency matrices often causes the agent's gradient to oscillate or the policy's explained variance to collapse. A stable representation that preserves the graph's spectral integrity while remaining hardware-aware is missing from current research.
\end{enumerate}

\section{Research Questions}
\label{sec:rqs}
Driven by the identified gaps, this thesis seeks to answer the following research questions:

\begin{enumerate}[label=RQ\arabic*., leftmargin=*, nosep]
    \item How can the SRv6 Maximum Segment Depth (MSD) physical limit be natively integrated as a hard hardware constraint within a Reinforcement Learning agent to guarantee 100\% packet parsing feasibility on programmable switches?
    
    \item In what way does a Graph Attention Network (GAT) architecture with a Static Adjacency matrix enhance the orchestrator's awareness of geo-distributed topologies compared to standard topology-blind Deep Reinforcement Learning agents?
    
    \item How does the integration of time-series traffic forecasting within a closed-loop orchestration pipeline enable proactive migration to outperform traditional reactive mechanisms in terms of service continuity and resource utilization?
    
    \item To what extent can the proposed JO-VPPM framework achieve measurable performance gains in acceptance ratio and latency whilst strictly adhering to hardware limitations compared to Integer Linear Programming (ILP) and heuristic baselines?
\end{enumerate}

\chapter{System Modeling and JO-VPPM Methodology}
\label{chap:method}

This chapter details the theoretical formalization of the 3S-COM architecture and the mathematical foundations of the JO-VPPM framework. To address the NP-hard nature of VNF placement under hardware-level data plane constraints, we establish a rigorous modeling of the substrate network and the service requests before deriving the Deep Graph Reinforcement Learning solution.

\section{Problem Formalization and Network Modeling}
\label{sec:math_modeling}
The orchestration of Service Function Chains (SFC) in a geo-distributed environment involves mapping logical service requests onto a physical substrate while ensuring that both computing and networking constraints are strictly satisfied.

\subsection{The Substrate Network Model}
We represent the substrate network as a weighted undirected graph $\mathcal{G}_s = (\mathcal{V}_s, \mathcal{E}_s)$, where $\mathcal{V}_s = \{v_1, v_2, \dots, v_n\}$ is the set of data center nodes ($n=10$ in this research) and $\mathcal{E}_s$ is the set of physical links connecting them. 

Each node $v \in \mathcal{V}_s$ is characterized by a multi-dimensional resource capacity vector $\mathbf{C}_v = [C_v^{cpu}, C_v^{ram}, C_v^{msd}]$. 
\begin{itemize}
    \item $C_v^{cpu} \in \mathbb{R}^+$: Total compute capacity in standardized units.
    \item $C_v^{ram} \in \mathbb{R}^+$: Total transient memory capacity.
    \item $C_v^{msd} \in \mathbb{Z}^+$: The \textbf{Maximum Segment Depth (MSD)} limit of the ingress switch at node $v$. This represents the hard physical boundary of the PISA-based parser, defined as the maximum number of 128-bit SIDs that can be processed in a single clock cycle.
\end{itemize}

The set of edges $\mathcal{E}_s$ is associated with a latency matrix $\mathbf{L} \in \mathbb{R}^{n \times n}$, where each element $L_{ij}$ represents the propagation delay between node $i$ and node $j$ calculated via the Haversine geodesic formula:
\begin{equation}
d = 2R \arcsin \left( \sqrt{\sin^2 \left( \frac{\phi_2 - \phi_1}{2} \right) + \cos \phi_1 \cos \phi_2 \sin^2 \left( \frac{\lambda_2 - \lambda_1}{2} \right)} \right)
\end{equation}
The propagation latency is then derived as $l_{ij} = d/v_{fiber} + p_{delay}$, where $v_{fiber}$ is the velocity of light in fiber optics and $p_{delay}$ is the node-specific processing delay.

\subsection{The SFC Request Model}
A service request $r \in \mathcal{R}$ is modeled as an ordered sequence of Virtual Network Functions (VNFs), defined by $\mathcal{G}_r = (\mathcal{F}_r, \mathcal{L}_r)$, where $\mathcal{F}_r = \{f_1, f_2, \dots, f_m\}$ is the set of functions and $\mathcal{L}_r$ represents the logical links between them.

For every request $r$, a resource demand vector $\mathbf{D}_r = [d_r^{cpu}, d_r^{ram}, d_r^{msd}]$ is specified. The parameter $d_r^{msd}$ is of particular importance, as it denotes the number of SRv6 Segment Identifiers (SIDs) required to encapsulate the specific function's behavior (e.g., \textit{End.DX2} or \textit{End.AM}).

The orchestration task is define as finding a mapping function $\mathcal{M}: \mathcal{F}_r \to \mathcal{V}_s$ such that:
\begin{equation}
\mathcal{M}(f_i) = v_j, \quad \forall f_i \in \mathcal{F}_r, v_j \in \mathcal{V}_s
\end{equation}
Simultaneously, the routing sub-problem must find a physical path $P_{ij} \subset \mathcal{E}_s$ for every logical link $(f_i, f_{i+1}) \in \mathcal{L}_r$.

\subsection{Mathematical Formalization of Hardware Constraints}
The JO-VPPM framework distinguishes itself by treating hardware limits as hard boundaries rather than soft penalties. 

\textbf{C1: Computing Resource Constraint.} The total CPU and RAM consumed at any node $v$ must not exceed its capacity:
\begin{equation}
\sum_{r \in \mathcal{R}_{active}} \sum_{f_i \in \mathcal{F}_r} x_{v, f_i} \cdot d_r^{cpu} \le C_v^{cpu}, \quad \forall v \in \mathcal{V}_s
\end{equation}
where $x_{v, f_i} \in \{0,1\}$ is a binary variable indicating if VNF $f_i$ is placed on node $v$.

\textbf{C2: SRv6 MSD Hard Constraint.} For every packet traversing the SFC path, the depth of the SID stack at the ingress of any switch node $v$ must be less than or equal to the switch's MSD capability:
\begin{equation}
\mathcal{S}_{depth}(r, v) \le C_v^{msd}, \quad \forall v \in \text{Path}(r)
\end{equation}
Unlike CPU, which is subtractive, the MSD constraint is \textit{per-packet header parsing depth}. If an orchestration decision results in a SID list longer than $C_v^{msd}$, the hardware will be physically unable to parse the header, leading to an immediate binary failure in the data plane.

\textbf{C3: SLA Latency Constraint.} For a service class $k$, the total end-to-end latency $\mathcal{T}_r$ must be bounded by the class-specific threshold $\tau_k$:
\begin{equation}
\mathcal{T}_r = \sum_{(f_i, f_{i+1}) \in \mathcal{L}_r} L_{\mathcal{M}(f_i), \mathcal{M}(f_{i+1})} + \sum_{f_i} \delta_{proc}(\mathcal{M}(f_i)) \le \tau_k
\end{equation}
where $\delta_{proc}$ represents the dynamic processing delay which varies with the node's current MSD utilization.

\subsection{Multi-Objective Optimization Goal}
The objective of the JO-VPPM orchestrator is to maximize the network utility while satisfying all binary constraints. We formulate the joint objective as:
\begin{equation}
\max \text{Utility} = \omega_1 \mathcal{A}_{ratio} - \omega_2 \mathcal{B}_{lat} - \omega_3 \mathcal{C}_{mig}
\end{equation}
where $\mathcal{A}_{ratio}$ is the SFC acceptance ratio, $\mathcal{B}_{lat}$ is the cumulative SLA violation score, and $\mathcal{C}_{mig}$ is the migration cost (switching cost) incurred when relocating VNFs to maintain proactive resilience.
The \textbf{3S-COM} (Smart, Scalable, Secure) framework operates as a decentralized closed-loop system designed for high-availability core networks. The framework is structured into four distinct functional layers that synchronize to achieve hardware-aware, proactive orchestration.

\begin{enumerate}
    \item \textbf{Data-plane Telemetry and State Extraction:} This module serves as the primary sensor for the orchestrator. It continuously harvests fine-grained telemetry data from the substrate nodes $\mathcal{V}_s$, including CPU load, memory residency, and ingress MSD utilization. The telemetry data is normalized and transformed into a real-time network state tensor $\mathbf{X}_t$, which serves as the fundamental input for the subsequent AI layers.
    \item \textbf{Traffic Forecasting via Bidirectional GRU (Bi-GRU):} Unlike reactive systems that wait for congestion to occur, 3S-COM employs advanced time-series forecasting. By analyzing temporal patterns in incoming packet-per-second (PPS) metrics, this module predicts impending traffic "Elephant" flows. The bidirectional nature of the GRU allows the system to perceive complex periodic surges that unidirectional models often overlook.
    \item \textbf{DGRL Orchestration (GAT):} The core intelligence module which maps the predicted state and current network topology onto an optimal orchestration action. Utilizing Graph Attention Networks, it prioritizes resource availability while respecting the hard spatial constraints of the network graph.
    \item \textbf{Stateless SRv6 Enforcement:} This layer translates the agent's placement or migration actions into standardized SRv6 instructions. It calculates the necessary SID list and encapsulates it within the IPv6 Segment Routing Header (SRH), enforcing the path across the P4 data plane without requiring flow-state maintenance in intermediate nodes.
\end{enumerate}

\subsection{Proactive Sensing: The Bi-GRU Mechanism}
To fulfill the "Smart" requirement of 3S-COM, we implement a \textbf{Bidirectional Gated Recurrent Unit (Bi-GRU)} for proactive traffic sensing. Traditional RNNs suffer from vanishing gradients and an inability to perceive long-term temporal dependencies. The GRU architecture mitigates this via hidden state gating.

For an input sequence $\mathbf{x}_t$, the forward GRU cell calculates:
\begin{align}
r_t &= \sigma(\mathbf{W}_r \cdot [\overrightarrow{h}_{t-1}, x_t] + b_r) \quad \text{(Reset Gate)} \\
z_t &= \sigma(\mathbf{W}_z \cdot [\overrightarrow{h}_{t-1}, x_t] + b_z) \quad \text{(Update Gate)} \\
\tilde{h}_t &= \tanh(\mathbf{W}_{\tilde{h}} \cdot [r_t \ast \overrightarrow{h}_{t-1}, x_t] + b_{\tilde{h}}) \\
\overrightarrow{h}_t &= (1 - z_t) \ast \overrightarrow{h}_{t-1} + z_t \ast \tilde{h}_t
\end{align}
where $\sigma$ is the sigmoid activation function and $\ast$ denotes the Hadamard product. 

In the bidirectional implementation, the output hidden state $\mathbf{H}_t$ is the concatenation of the forward state $\overrightarrow{h}_t$ and the backward state $\overleftarrow{h}_t$:
\begin{equation}
\mathbf{H}_t = [\overrightarrow{h}_t \parallel \overleftarrow{h}_t]
\end{equation}
By perceiving the sequence from both temporal directions, the 3S-COM agent can distinguish between transient noise and structural "Surge" patterns, triggering a \textbf{Proactive Migration} flag if the predicted intensity $\hat{x}_{t+1}$ exceeds the security threshold $\Theta_{vio}$.

\section{Deep Graph Reinforcement Learning: The JO-VPPM Engine}
To satisfy the requirements of topology-aware orchestration under hard data plane constraints (\textbf{RQ2}), we introduce the Deep Graph Reinforcement Learning (DGRL) engine. This module replaces standard topology-blind neural networks with a graph-centric intelligence.

\subsection{Markov Decision Process (MDP) Mapping}
The orchestration problem is modeled as a Markov Decision Process defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$.

\begin{itemize}
    \item \textbf{State Space ($\mathcal{S}$):} The observation vector $s_t \in \mathbb{R}^{48}$ provides a comprehensive view of the network. It is composed of the node feature matrix $\mathbf{F}_t \in \mathbb{R}^{10 \times 4}$ (CPU, RAM, MSD\_Used, MSD\_Free), the current request vector $\mathbf{R}_t \in \mathbb{R}^3$, and the one-hot traffic class encoding $\mathbf{C}_t \in \{0,1\}^5$. This high-dimensional representation ensures the agent can perceive both local node saturation and global service requirements.
    \item \textbf{Action Space ($\mathcal{A}$):} We define a multi-discrete action space $a_t \in \mathcal{V}^2$, where the agent simultaneously selects two substrate nodes to host the VNFs of the incoming SFC request.
    \item \textbf{Reward Function ($\mathcal{R}$):} The scalar reward signal used to guide the policy toward feasibility and efficiency.
\end{itemize}

\subsection{Graph Attention Network (GAT) Mechanism}
Standard neural networks treat the 10-node network state as a flat vector, losing the critical spatial relationships between nodes. Our framework utilizes **Graph Attention Networks (GAT)** \cite{velivckovic2017graph} to extract topological features. 

The input to each GAT layer is a set of node features, $\mathbf{h} = \{\vec{h}_1, \vec{h}_2, \dots, \vec{h}_n\}, \vec{h}_i \in \mathbb{R}^F$. The layer produces a new set of node features $\vec{h}_i' \in \mathbb{R}^{F'}$. 

A shared linear transformation, parametrized by a weight matrix $\mathbf{W} \in \mathbb{R}^{F' \times F}$, is applied to every node. We then compute a self-attention mechanism $a: \mathbb{R}^{F'} \times \mathbb{R}^{F'} \to \mathbb{R}$, which yields the attention coefficients:
\begin{equation}
e_{ij} = \text{LeakyReLU}\left(\vec{a}^T [\mathbf{W}\vec{h}_i \parallel \mathbf{W}\vec{h}_j]\right)
\quad \forall j \in \mathcal{N}_i
\end{equation}
where $\mathcal{N}_i$ is the neighborhood of node $i$ determined by the **Static Adjacency Matrix** $\mathcal{A}$. The coefficients are normalized across all neighbors using the softmax function:
\begin{equation}
\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k \in \mathcal{N}_i} \exp(e_{ik})}
\end{equation}

To stabilize the learning process and capture multiple aspects of the topology (e.g., both latency-adjacent and capacity-adjacent relations), we utilize $K=4$ independent attention heads. The final output is the concatenation (or average) of the heads:
\begin{equation}
\vec{h}_i' = \sigma \left( \sum_{k=1}^K \alpha_{ij}^k \mathbf{W}^k \vec{h}_j \right)
\end{equation}

A fundamental engineer decision in JO-VPPM is the use of a **Static Adjacency Matrix**. While dynamic adjacency might seem intuitive, it disrupts the graph Fourier transform properties, leading to reward instability. Our GAT heads learn to extract dynamic metrics (MSD/CPU) through the node feature tensor while maintaining a consistent perception of the physical fiber distance through the static graph structure.

\subsection{Maskable PPO and Invalid Action Masking}
Traditional Reinforcement Learning relies on exploration-exploitation trade-offs where the agent learns from "mistakes" (penalties). However, in critical telecommunications infrastructure, an "illegal" placement (e.g., violating a hard MSD limit) results in an immediate service blackout.

To enforce \textbf{Hardware Safety}, we integrate **Invalid Action Masking** within the **Proximal Policy Optimization (PPO)** framework \cite{huang2022closer}. Let $\mathcal{Z}(s)$ be the set of feasible actions calculated by the Masking Layer based on current CPU and MSD residuals. The policy distribution $\pi_\theta(a|s)$ is modified before the softmax layer:
\begin{equation}
\hat{\pi}_\theta(a|s) = 
\begin{cases} 
\frac{\exp(z_a)}{\sum_{j \in \mathcal{Z}(s)} \exp(z_j)} & \text{if } a \in \mathcal{Z}(s) \\
0 & \text{otherwise}
\end{cases}
\end{equation}
where $z_a$ are the raw logits from the GAT-policy network. By setting the logits of unfeasible actions to $-\infty$, the agent's exploration is 100\% confined to the physically feasible space $\Omega$. This ensures that the JO-VPPM framework generates zero "Hardware-Invalid" decisions throughout its lifecycle, significantly outperforming standard "soft-penalty" RL agents.

\section{Adaptive Lagrangian Penalty and Reward Design}
The JO-VPPM agent optimizes for a multi-objective reward function $R_t$. While Invalid Action Masking handles local hardware availability, the global satisfaction of service-level agreements (SLA) requires an intelligent reward signal. We introduce the **Adaptive Lagrangian Penalty** to dynamically enforce these long-term constraints (\textbf{RQ1}).

\subsection{Mathematical Derivation of the Adaptive Penalty}
Standard RL models often struggle with fixed penalties, as a penalty that is too small leads to constraint violation, while a penalty that is too large leads to premature convergence to sub-optimal policies. We frame the orchestration as a constrained optimization problem:
\begin{align}
\max_{\theta} \quad & J(\pi_\theta) = \mathbb{E} [ \sum_{t=0}^T R_{base}(s_t, a_t) ] \\
\text{subject to} \quad & \mathbb{E} [ \sum_{t=0}^T C_{vio}(s_t, a_t) ] \le \Gamma
\end{align}
where $C_{vio}$ is the constraint violation cost and $\Gamma$ is the maximum tolerable violation threshold. The Lagrangian form of this objective is:
\begin{equation}
L(\theta, \lambda) = J(\pi_\theta) - \lambda \left( \mathbb{E} [ C_{vio} ] - \Gamma \right)
\end{equation}
In JO-VPPM, we implement an adaptive update law for the multiplier $\lambda$ based on the agent's empirical performance across a sliding window of $\Omega=20$ steps. Let $V_{rate}$ be the observed violation rate:
\begin{equation}
\lambda_{t+1} = \text{clip}\Big(\lambda_{t} + \eta \cdot (V_{rate} - \tau_{target}), \lambda_{min}, \lambda_{max} \Big)
\end{equation}
where $\eta$ is the learning rate of the dual multiplier. This ensures that $\lambda$ increases exponentially when violations are high, effectively "tilting" the reward landscape to favor safe actions, and decreases when the agent operates within the safe bounds, allowing it to focus on maximizing resource efficiency.

\subsection{Multi-Objective Reward Synthesis}
The composite reward function is designed to balance conflicting objectives: acceptance, latency, resource balance, and stability.
\begin{equation}
R_{total} = (R_{accept} \cdot \Psi_{res}) + B_{knap} + B_{core} - P_{swi} - P_{sla}
\end{equation}

\begin{itemize}
    \item \textbf{Knapsack Bonus ($B_{knap}$):} To prevent the agent from biased towards small, "easy" requests, we implement a bonus proportional to the request's resource density:
    \begin{equation}
    B_{knap} = \sigma \cdot \left( d_r^{cpu} \cdot d_r^{msd} \right)
    \end{equation}
    This encourages the agent to find feasible placements for "Elephant" flows, which are critical for high-throughput 5G services.
    \item \textbf{Core Hub Incentive ($B_{core}$):} Large requests are incentivized to reside on Core DCs (Hanoi, Da Nang, HCM) which possess higher MSD headroom and processing stability.
    \item \textbf{Switching Penalty ($P_{swi}$):} Triggered when the agent's decision at $t$ differs from $t-1$ for the same SFC, capturing the overhead of migration (FIB updates, state transfer).
    \item \textbf{SLA Violation Penalty ($P_{sla}$):} The adaptive penalty term derived from the Lagrangian multiplier:
    \begin{equation}
    P_{sla} = \lambda_t \cdot \mathbb{I}(\mathcal{T}_r > \tau_k) \cdot \frac{\mathcal{T}_r - \tau_k}{\tau_k}
    \end{equation}
    where $\mathcal{T}_r$ is the calculated total latency and $\tau_k$ is the SLA threshold.
\end{itemize}

\subsection{Resource Balancing and Entropic Regularization}
The final component $\Psi_{res}$ in the reward function ensures that resources are not disproportionately consumed at a single hub. It is calculated as the inverse variance of the CPU utilization across the 10 nodes. Furthermore, the PPO objective includes an entropy term $H(\pi_\theta)$ to maintain exploration:
\begin{equation}
L^{PPO}(\theta) = \hat{\mathbb{E}}_t [ L^{CLIP}(\theta) + c_1 L^{VF}(\theta) + c_2 H(\pi_\theta) ]
\end{equation}
The integration of GAT-based feature extraction with this adaptive reward structure allows JO-VPPM to maintain a 63\% higher acceptance ratio compared to baseline heuristic algorithms in high-congestion scenarios.

\section{Algorithm Complexity and Theoretical Scalability}
To evaluate the practical feasibility of JO-VPPM in carrier-grade 5G networks, we analyze the computational complexity of the orchestration engine.

\subsection{Computational Complexity of JO-VPPM}
The runtime performance is dominated by the inference phase of the Graph Attention Network. For a substrate network with $N = |\mathcal{V}|$ nodes and $M = |\mathcal{E}|$ edges, the complexity of a single GAT layer with $K$ attention heads and $F'$ output features is:
\begin{equation}
\mathcal{O}(N \cdot F \cdot F' \cdot K + M \cdot F' \cdot K)
\end{equation}
Since the number of nodes in a typical national backbone (e.g., Vietnam Backbone) is relatively small ($N \approx 10-100$), and the adjacency matrix is sparse, the GAT inference occurs in sub-millisecond time. This contrasts sharply with traditional Integer Linear Programming (ILP) solvers, which exhibit exponential complexity $\mathcal{O}(2^N)$ and become intractable for large-scale geo-distributed deployments.

\subsection{Scalability via Static Graph spectral Stability}
The decision to utilize a \textbf{Static Adjacency Matrix} (\textbf{RQ2}) significantly enhances the framework's scalability. By decoupling the static physical topology from the dynamic node feature updates, the GAT parameters $W^k$ remain valid even as traffic intensity fluctuations occur. This prevents the need for frequent re-training (retraining overhead), allowing the JO-VPPM agent to maintain high accuracy across varying load profiles without a proportional increase in computational cost.

\subsection{Memory Footprint and Hardware Offloading}
The memory overhead of the JO-VPPM agent is characterized by the storage of the GAT weights and the state tensor $\mathbf{X}_t$. Given the discrete nature of the 48-dimensional state vector, the total footprint is less than 50MB, making it suitable for deployment on edge compute nodes or integration into the Network Functions Virtualization Infrastructure (NFVI) control plane. Future implementations could potentially offload the GAT matrix multiplications directly onto \textbf{NVIDIA BlueField-3 DPUs} or programmable switch control units to further reduce the orchestration latency to the microsecond range.

\section{System Operations and SFC Lifecycle Management}
To bridge the gap between AI decision-making and data plane enforcement (\textbf{RQ3}), we formalize the operational lifecycle of a service request within the JO-VPPM framework.

\subsection{Placement to Path Mapping and SRv6 Embedding}
The joint optimization process produces a node assignment $\mathbf{v} = \{v_1, v_2, \dots, v_m\}$. However, for data plane steering, this must be transformed into a sequence of hop-by-hop instructions. Given the adjacency matrix $\mathcal{A}$, the shortest path $\mathcal{P}_{i, i+1}$ between any two scheduled nodes $v_i$ and $v_{i+1}$ is computed via the Dijkstra algorithm:
\begin{equation}
\mathcal{P}_{i, i+1} = \arg \min_{P \in \Gamma(v_i, v_{i+1})} \sum_{e \in P} L_e
\end{equation}
where $L_e$ is the link latency. The resulting physical path is then mapped to an SRv6 Segment List $\mathcal{S} = [SID_{v_1}, SID_{f_1}, SID_{v_2}, SID_{f_2}, \dots]$. 

The enforcement module ensures that for every ingress node $v_{ingress}$, the encapsulated SRH header does not exceed the MSD limit $C_{v_{ingress}}^{msd}$. If $\text{len}(\mathcal{S}) > C_{v_{ingress}}^{msd}$, the framework triggers a \textbf{Segment Compression} logic or forces a re-routing to an intermediate core hub with higher segment processing capacity.

\subsection{Proactive Migration Triggering Logic}
A core novelty of JO-VPPM is its ability to migrate VNFs pre-emptively. Let $\mathcal{X}(t)$ be the current traffic intensity and $\hat{\mathcal{X}}(t+k)$ be the prediction from the Bi-GRU module for a future window $k$. 

The migration flag $\mathcal{M}_r$ for an existing request $r$ is triggered if:
\begin{equation}
\mathbb{P}(\hat{\mathcal{X}}(t+k) > \Phi_{cap}) > \alpha_{risk}
\end{equation}
where $\Phi_{cap}$ is the node capacity and $\alpha_{risk}$ is a configurable risk-tolerance parameter. When $\mathcal{M}_r = 1$, the orchestrator calculates a new optimal mapping $\mathcal{M}'$ and initiates the state transfer. The "Switching Penalty" $P_{swi}$ in the reward function ensures that migration only occurs when the expected gain in SLA satisfaction exceeds the transient overhead of the relocate operation.

\subsection{Algorithm Stability and Training Dynamics}
The convergence of the JO-VPPM agent is governed by the consistency of the value function $V(s)$. By utilizing a \textbf{Static Adjacency Matrix}, we ensure that the structural embeddings produced by the GAT layers remain invariant to load fluctuations. This architectural choice prevents the "feature drift" common in dynamic graph reinforcement learning, allowing the PPO agent to achieve a stable Explained Variance ($\approx 0.42$) even in environments with highly stochastic traffic surges.

\section{Analysis and Discussion}
The empirical results provide a comprehensive answer to research questions \textbf{RQ2} and \textbf{RQ4}.

\subsection{Near-Optimal Performance (Optimality Gap)}
With an acceptance ratio of \textbf{88.78\%}, JO-VPPM only trails the theoretical performance ceiling of the Optimal (ILP) algorithm by approximately \textbf{5.3\%}. This is remarkable considering that while ILP must exhaustively search 100 combinations per step, the JO-VPPM agent requires less than 5ms to deliver a decision using the trained GAT model. This result validates the capacity of Deep Graph Reinforcement Learning to learn complex resource allocation patterns.

\subsection{Hardware Safety and Action Masking}
The superiority of JO-VPPM over Decoupled AI is clearly demonstrated through the MSD violation rate. The Decoupled AI algorithm, lacking the integration between placement and routing, suffers from a hardware violation rate of \textbf{29.8\%}—a figure that is unacceptable in practical telecommunication networks. In contrast, through the utilization of \textbf{Action Masking} and the \textbf{Adaptive Lagrangian Penalty}, JO-VPPM reduced this rate to just \textbf{5.34\%}, ensuring data integrity across the VNF chain.

\subsection{Energy Efficiency and Load Balancing}
A key finding during the Stress-test is the sustainability of the model. Although the Optimal algorithm accepts more requests, it consumes \textbf{8.27 MJ} of energy. JO-VPPM consumes only \textbf{6.65 MJ} (a 19\% reduction), indicating that the Agent learned an intelligent VNF "consolidation" strategy to optimize performance-per-watt across DC nodes.

\chapter{Conclusion and Future Work}
\label{chap:conclusions}

\section{Summary of Technical Contributions}
This research addressed the critical challenge of hardware-aware Service Function Chaining (SFC) in geo-distributed 5G core networks. By proposing the \textbf{JO-VPPM} framework and its underlying \textbf{3S-COM architecture}, we have successfully integrated topological intelligence with physical data plane constraints. 

Our key findings demonstrate that:
\begin{enumerate}
    \item \textbf{Hardware Integrity:} Traditional orchestration algorithms that treat the Maximum Segment Depth (MSD) as a soft penalty invite inevitable deployment failures. JO-VPPM, by treating MSD as a hard boundary through an Adaptive Lagrangian Penalty, achieved a reduction in hardware violations from 29.8\% down to 5.34\%.
    \item \textbf{Topological Awareness:} The utilization of Graph Attention Networks (GAT) with a Static Adjacency matrix provides the AI agent with a persistent "geographical sense," allowing it to navigate the 10-node Vietnam Backbone with an acceptance ratio that approaches the optimal ILP benchmark.
    \item \textbf{Proactive Resilience:} The integration of Bi-GRU-based traffic forecasting transforms the orchestrator from a reactive system into a proactive intelligence, mitigating congestion before it impacts end-user SLA.
\end{enumerate}

\section{Future Research}
The evolution of 6G and Open RAN (O-RAN) presents new opportunities for JO-VPPM. Future work will investigate \textbf{Multi-Agent Reinforcement Learning (MARL)} for federated orchestration across international backbone boundaries and the offloading of GNN inference tasks directly onto P4-programmable smartNICs to achieve microsecond-level decision latency.

\chapter{DGRL Policy Architecture}
\label{appendix:neural_arch}
The JO-VPPM agent utilizes a custom \textbf{GNNActorCriticPolicy} built with PyTorch.
\begin{itemize}
    \item \textbf{Feature Extractor:} Graph Attention Network (GAT) with 2 layers, 4 attention heads each, and 64 hidden dimensions.
    \item \textbf{Activation:} LeakyReLU ($\alpha=0.2$).
    \item \textbf{Normalization:} LayerNorm applied to node embeddings to prevent gradient explosion in deep graphs.
    \item \textbf{Policy Heads:} Shared MLP of $[256, 128]$ units branching into separate Actor (Policy) and Critic (Value) networks.
\end{itemize}
