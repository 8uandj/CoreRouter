- The 60-cell TTL/mask intervention is complete. `python3 scripts/rev1/summarize_mask_expiry_intervention.py` validates both modes, all seed trace hashes, and the current-policy rows against the refreshed benchmark. The intervention retains the pre-expiry observation, so it is not a full runtime order change or a proof that a fix improves acceptance.
